# OmniPost Admin Portal

The **OmniPost Admin Dashboard** is a standalone, security-hardened Next.js 15 web application designed for platform administrators, customer operations, finance managers, and support staff. It operates in production at `https://admin-gamma-ten-89.vercel.app` and connects to the live NestJS API server on Render at `https://omnipost-api.onrender.com`.
